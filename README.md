## 🏢 عن المشروع

موقع رسمي لشركة **لاڤيدا بروبيرتز**، مبني بتقنيات حديثة ويعمل بشكل كامل على جميع الأجهزة. يعرض خدمات الشركة العقارية، مشاريعها، فريقها، وطريقة التواصل معها.

## ✨ المميزات

- 🏠 عرض المشاريع العقارية (سكني، تجاري، ساحلي)
- 📋 نموذج تواصل مع حفظ الطلبات محلياً
- 💬 مساعد واتساب تفاعلي
- 📱 تصميم متجاوب يعمل على جميع الأجهزة (Responsive)
- 🌙 دعم كامل للغة العربية واتجاه RTL

## 🛠️ التقنيات المستخدمة

- **React 19** + **TypeScript**
- **Vite 6**
- **Tailwind CSS v4**
- **Motion (Framer Motion)**
- **Lucide React Icons**

## 🚀 تشغيل المشروع محلياً

**المتطلبات:** Node.js

```bash
# 1. تثبيت المكتبات
npm install

# 2. تشغيل السيرفر
npm run dev
```

الموقع سيعمل على: `http://localhost:3000`
